# SoC fabric: declare the bus, never write it

## When this applies
Any design with two or more initiators sharing a target (CPU + DMA, two harts,
CPU + GPU + scan-out), any AXI4 / AXI-Lite / APB bus, any block whose job is
"arbiter", "crossbar", "interconnect", "bus bridge" or "address decoder".
That is almost every SoC.

## The rule
The fabric is a **primitive**, generated by the engine from a declarative
spec over silicon-proven IP (pulp-platform `axi`: crossbar, AXI4→AXI-Lite,
AXI-Lite→APB, error slave, ID remap, width converters). The RTL agent MUST
NOT hand-write an arbiter, crossbar, address decoder, protocol bridge or
`cs_fabric_*` module. A hand-written interconnect is rejected at review
(the SoC benchmark's hand-written `axi_arbiter` tied `rready/bready` to 1,
cited assertions that did not exist and dropped write errors).

## How to declare it (block diagram)
Emit ONE block per bus, for example:

```json
{
  "name": "fabric",
  "kind": "primitive",
  "primitive": "cs_fabric",
  "tier": 0,
  "subsystem": "interconnect",
  "description": "SoC bus: 2 harts + GPU + scan-out onto RAM, APB peripherals, GPU registers",
  "golden_exempt": true,
  "no_golden_reason": "generated from FabricSpec over pulp-platform axi; verified by its generated cocotbext-axi testbench",
  "fabric": {
    "name": "soc",
    "data_width": 64, "addr_width": 32,
    "masters": [
      {"name": "hart0", "protocol": "axi4", "id_width": 4, "max_outstanding": 8},
      {"name": "hart1", "protocol": "axi4", "id_width": 4, "max_outstanding": 8},
      {"name": "gpu",   "protocol": "axi4", "id_width": 4, "max_outstanding": 4}
    ],
    "slaves": [
      {"name": "ram",      "protocol": "axi4",     "base": "0x80000000", "size": "0x8000000"},
      {"name": "periph",   "protocol": "apb",      "base": "0x10000000", "size": "0x10000"},
      {"name": "gpu_regs", "protocol": "axi_lite", "base": "0x10020000", "size": "0x1000"}
    ],
    "ordering": "per_id",
    "err_slave": true
  }
}
```

* Every **master** connects to the fabric with an edge whose
  `handshake_protocol` is `axi4`; its port prefix on the master block is
  `m_<bus>` and on the fabric `s_<master name>`.
* Every **slave** connects from the fabric with `axi4`, `axi_lite` or `apb`;
  the fabric port prefix is `m_<slave name>`, the slave's is `s_<bus>`.
* Signal names are the canonical AMBA ones (`awvalid`, `awready`, `awaddr`,
  `wdata`, `wstrb`, `wlast`, `bresp`, `arvalid`, `rdata`, `rlast`, ...; APB:
  `psel`, `penable`, `pwrite`, `paddr`, `pwdata`, `pstrb`, `pready`,
  `prdata`, `pslverr`). Ports are `<prefix>_<signal>`.
* Slave sizes are powers of two, bases aligned to their size, regions
  disjoint. Unmapped addresses answer DECERR (`err_slave`).
* All masters share one `id_width`; the fabric's slave-side ids are
  `id_width + log2(masters)` wide.
* Timing knobs (omit for the defaults): `latency_mode` `"cut_all_ports"`
  (default; every AXI channel registered at both crossbar sides) or
  `"cut_all_ax"` (only AW/AR cut: W/B/R combinational, fails timing on wide
  fabrics); `slave_cut` (default `true`) adds an `axi_cut` on every slave
  port and registers both sides of each AXI-Lite/APB converter (full-AXI cut
  before `axi_to_axi_lite`, AXI-Lite cut after it, pipelined `axi_lite_to_apb`).

## What stays custom
Coherence (snooping/directory controllers, coherent caches) is a custom
block that sits on the fabric as a master; the fabric is non-coherent. DMA
engines, MMIO register files and memory controllers are ordinary blocks on
the slave side. Clock-domain crossings are not generated yet.

## What you get
`rtl/<subsystem>/cs_fabric_<name>.v` (plain Verilog-2001, elaborated by
yosys-slang from the vendored SystemVerilog), a cocotb testbench that checks
decode, decode errors, bursts, backpressure and fairness, and the flat port
list every neighbour's contract must match. The fabric block skips the uArch
/ RTL / TB LLM stages; its synthesis and PPA run like any other block.
