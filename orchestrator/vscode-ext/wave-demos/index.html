Heads up: the Surfer-hosted and fliplot demos run on a different origin from this server, so the VCD has to be fetched cross-origin. The /api/artifacts/ endpoint ships Access-Control-Allow-Origin: * so this should just work. If a demo can't auto-load the file, you can also download it manually and drag it into the viewer: adder32_dump.vcd.
